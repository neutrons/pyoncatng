=========
pyoncatng
=========

``pyoncatng`` is a Python package that handles **login to** and **data fetching
from** `ONCAT <https://oncat.ornl.gov/>`_ (the ONCat data catalog), built on top
of the `pyoncat <https://oncat.ornl.gov/>`_ library.
